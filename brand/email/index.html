How to Install in Gmail or Apple Mail

  1. Click Copy Signature above on whichever variant you want.
  2. Gmail: Click the Gear icon ⚙ → See all settings → Scroll down to Signature → Create new or edit → Paste directly into the signature box (Cmd + V). Scroll to the bottom and click Save Changes.
  3. Apple Mail: Mail → Settings → Signatures → Click + → Uncheck "Always match my default message font" → Paste (Cmd + V).
  4. All logo assets are hosted from the live CDN at mukpost.com/brand/ so recipients see them automatically with zero attachments.
